# "世界记忆冠军大卫哥"视频下架与补档

> **存档对象**：B 站 UP 主「世界记忆冠军大卫哥」在武汉大学图书馆事件中的相关内容，以及其视频被下架后由第三方账号"补档"复活的现象。
> **存档方式**：仅记录元数据与公开报道描述，**不搬运视频内容本体**。

---

## 为什么这个档案存在

在武大图书馆事件中，该 UP 主的相关视频反复经历「上传 → 下架 → 补档 → 再传播」。

这个过程本身是有记录价值的事实：
- 它记录了平台审核与创作者规避之间的拉锯
- 它显示了"下架"在中文互联网上并不等于"消失"
- 它也涉及**公开当事人隐私**这一争议行为

**本档案不评价其动机**（"为了公共利益"还是"为了流量"），只登记可核验的元数据。

## 争议行为的公开描述

以下描述来自微博认证博主「判难」2025-09-21 的公开评论，属**观点**，但与元数据可交叉印证部分已标注：

| 描述 | 性质 | 可印证性 |
|---|---|---|
| 使用"全球通缉"等煽动性标题 | 行为描述 | 标题风格与现存视频一致 |
| 公开当事人隐私（姓名、学校、留学去向） | **行为指控** | `pending-source`，需原始视频内容佐证 |
| 原视频下架后以"补档"形式复活 | 行为描述 | ✅ 已印证：存在专门补档账号 |
| 维持高播放量 | 行为描述 | ✅ 可查当前播放数据 |
| 核心驱动力是商业流量 | **主观判断** | 无法核验，属观点 |
