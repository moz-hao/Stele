# 武汉大学图书馆事件（2023–2025）

> **一句话**：2023 年 7 月，武汉大学一名女生称在图书馆自习时遭同校男生性骚扰，同年 10 月网络曝光，校方给予男生记过处分；2025 年法院一审、二审均驳回女生的性骚扰诉讼请求，校方随后撤销原处分并对相关人员问责。

## 本案的关键事实（均有出处）

1. **司法层面**：一审（2025-07-25，武汉经济技术开发区人民法院）驳回杨某媛全部诉讼请求；二审（2025-09-17，武汉市中级人民法院）维持原判。→ 见 `01-facts.md`
2. **校纪层面**：原给予肖某瑫记过处分，2025-09-20 通报撤销。→ 见 `01-facts.md`
3. **学位层面**：校方复核后维持授予杨某媛硕士学位，认定未发现抄袭、主观造假、篡改数据、编造结论等学术不端行为，但存在"百余处不规范问题"。→ 见 `01-facts.md`
4. **问责层面**：3 名党务干部受党内警告处分，导师郭某飞被约谈并暂停研究生招生资格两年。→ 见 `01-facts.md`
5. **谣言层面**：官方点名否定 8 条网传信息。→ 见 `04-debunked.md`
