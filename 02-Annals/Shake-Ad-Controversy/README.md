# 开屏"摇一摇"广告争议（2021—2026）

> **一句话**：用户打开 App 时轻微晃动手机即被跳转到电商/外卖平台，2021 年起被消协点名、2022 年出台技术标准、2023 年工信部明令禁止，但直到 2026 年仍有 App 因"窗口乱跳转"被通报——被媒体称为"数字牛皮癣"。

---

## 为什么这类事件值得存档

这是"热议极高、却极易被稀释"的典型：

1. **痛感普适**：几乎每个智能手机用户都遭遇过
2. **有明确规范**：不是"网友觉得烦"，而是工信部明文禁止
3. **屡禁不止**：规范出台三年后仍在通报，说明执行与利益结构的矛盾
4. **讨论易失焦**：每次热点都被"双11""618"周期性冲刷，缺乏长期记录

存档它的意义不是骂广告，而是**留下"规范什么时候立的、立了之后有没有用"的时间证据**。

## 一个必须记住的数据

江苏省消保委 2023-11 的投票（样本为参与投票网民）：

| 指标 | 比例 |
|---|---|
| 经常遇到"摇一摇"跳转 | **77.22%** |
| 对"摇一摇"开屏广告持"厌恶"态度 | **94.94%** |
| 认为该功能侵犯自己权益 | **93.67%** |
| 支持叫停开屏"摇一摇"跳转 | **74.68%** |

**注意**：这是消保委自行发起的网络投票，非随机抽样调查，存在自选择偏差，不能外推为全体用户比例。引用时须注明这一点。
